# Changelog

The user guides describe the current version. The version notes linked below are retained as historical records.

## Unreleased

### Publication review

- Added an October 12 assessment of the actual public 0.6.3 APK for GitHub beta and paid Meta Store distribution, with reproducible artifact findings and a prioritized completion plan.
- Recorded confirmed packaging failures, bundled operator tooling, licensing/privacy gaps, and outstanding device acceptance. No runtime changes or new APK.

### Documentation

- Separated the introduction, technical reference, and knowledge base following the LanLens example.
- Aligned current gesture and update instructions with 0.6.3.
- Added English XML comments for important C# interfaces and explanations at state transitions.
- Translated repository documentation and historical release notes into English; retained German and English in the app.
- No runtime behavior changes or new APK version.

## 0.6.3

HA area catalog including empty areas, protected navigation, exclusive interaction using either hand, captured fist target while looking away, and spatial light arcs. [Instructions](docs/VERSION-0.6.3.md) · [Release](docs/RELEASE-0.6.3.md).

## 0.6.2

Visible filters, shared menu rendering order, entities restricted to the current Quest room, adjustment ticks, and gesture feedback. [Details](docs/VERSION-0.6.2.md).

## 0.6.1

Brighter menu, revised 3D symbols, and adjustable watch position. Exclusion of local SDK developer data from the build. [Details](docs/VERSION-0.6.1.md).

## 0.6.0

Gaze reticle, pinch, fist rotation, and fireball on opening the hand; distance-scaled sensor labels and revised watch. [Details](docs/VERSION-0.6.0.md).

## 0.5.0

Meta Interaction SDK, scrollable list, sliders, HA watch, system keyboard, German/English, sounds, and media frames. [Details](docs/VERSION-0.5.0.md).
