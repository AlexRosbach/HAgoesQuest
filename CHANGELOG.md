# Changelog

A short feature history. Installation and the user guide describe the current version.

## Repository cleanup

- Present the project as a personal case study with a 23-second control demo and an invitation to fork.
- Remove development tests, mock server, UI probes, test CI, unused XR simulation assets, and historical research/acceptance reports.
- Retain the app, build tools, user guides, asset provenance, and third-party notices. No new APK.

## 0.6.3

HA area catalog including empty areas, protected navigation, exclusive interaction using either hand, captured fist target while looking away, and spatial light arcs.

## 0.6.2

Visible filters, shared menu rendering order, entities restricted to the current Quest room, adjustment ticks, and gesture feedback.

## 0.6.1

Brighter menu, revised 3D symbols, and adjustable watch position. Exclusion of local SDK developer data from the build.

## 0.6.0

Gaze reticle, pinch, fist rotation, and fireball on opening the hand; distance-scaled sensor labels and revised watch.

## 0.5.0

Meta Interaction SDK, scrollable list, sliders, HA watch, system keyboard, German/English, sounds, and media frames.
