# Generated interface assets

Created using the built-in Imagegen tool. Original PNG assets preserve alpha transparency. Unity imports them at a maximum of 512 pixels for the headset UI. No third-party icon set is used.

## lamp.png

Use case: stylized-concept. Asset type: single production UI icon for a Quest 3 mixed-reality smart-home app, PNG with real alpha transparency. Subject: one recognizable lightbulb, beautiful sculpted frosted glass with teal rim and softly warm luminous center. Style: premium restrained 3D interface icon, clean silhouette, front three-quarter view, readable at small size. Match a dark navy and teal interface. Centered, generous empty transparent padding, no background plane, no enclosing tile, no lettering, no watermark, no other objects, no cast shadow outside the object.
