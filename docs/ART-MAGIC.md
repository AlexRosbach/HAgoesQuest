# Generierter Magie-Effekt

Werkzeug: eingebautes `image_gen`, kein CLI-Fallback.

Projektdatei: `Assets/HAgoesQuest/Resources/Effects/green-fireball.png` (echter Alphakanal). Unity importiert die Textur für die Quest mit maximal 512 Pixeln. Die Originalgrafik bleibt unverändert; Unity erzeugt die Bewegung und den Schweif zur Laufzeit.

## Verwendeter Prompt

Use case: stylized-concept. Asset type: transparent game VFX sprite for a Meta Quest AR magical fireball. A single compact spherical emerald green magical flame orb, brilliant pale mint core, rich saturated green swirling flame tongues and wispy jade edges, soft luminous translucent falloff. Centered isolated front view, roughly circular silhouette, ample transparent padding all sides. Polished fantasy game effect, readable at small size. Actual transparent background, no black backdrop, no ground, no shadow, no hand, no person, no environment, no text, no border, no sheet, no multiple objects. The orb will be animated in Unity with a green particle trail.
