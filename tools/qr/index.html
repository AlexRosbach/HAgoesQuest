Dein Zuhause per QR verbinden

Erzeuge deinen Zugangscode auf dem Handy oder Computer. Der Code wird ausschließlich auf diesem Gerät erzeugt. Es werden keine Zugangsdaten versendet oder gespeichert.

Auf der Quest: Verbindung → Token per QR-Code → Scan starten. Danach die Adresse prüfen und verbinden.

Der QR-Code enthält deinen Token. Zeige ihn nur deiner Quest und schließe ihn nach dem Einlesen.
